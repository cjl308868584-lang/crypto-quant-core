# ADR-0029：基线失败归因与仅前向 Challenger

日期：2026-07-28
状态：已接受

## 背景

v0.28 已证明简单 LONG 基线在 419 个 archive OOS 事件中 8/8 个季度成本后
为负，Logistic 也未改善概率质量。继续增加 AI 会掩盖简单策略本身的问题，
但只看最终净值又无法区分毛边际、费用、退出路径与收益集中度。

## 决策

1. 在查看真实分组结果前，固定 fold、退出原因、持有时间以及 SMA 距离、
   5-bar 动量、年化波动和平均区间比例的全部分组边界。
2. 每组同时报告 gross PnL、精确双边 fee、net PnL、fee flip 与正标签率；
   空分组也保留，禁止移动边界或只展示有利分组。
3. 归因只描述已看 archive，不构成统计门、正式 OOS 或盈利证据。
4. 冻结一个单一简单 challenger：
   `SPOT_LONG_SMA20_COST_MARGIN_MOMENTUM_V2`。SMA20 距离至少为固定双边
   slippage + fee 名义预算 `0.005`，同时 5-bar log return 必须大于 0。
5. challenger 不在 v0.29 上运行历史收益，不从分组结果选择新阈值。未来实现
   必须从完整事件流重新生成 episode；被拒绝的入场不得消费持有窗口。
6. 最早允许的 prequential forward 起点是
   `2026-07-29T00:00:00.000Z`，只接受决策前已经保存的输入、成本和输出。

## 实际归因

全部 780 个事件的保守成交代理 gross PnL 已为 `-1292.32171 USDT`，费用
进一步拖累 `2337.76291479 USDT`。419 个 pooled archive OOS 事件在费用前
也亏损 `-957.969754 USDT`，费用后为 `-2213.351088241 USDT`。

因此“只要降低费率就能赚钱”被否决：费用很重要，但当前入场/退出路径在费用
前也没有正边际。

退出归因显示，203 个 `SMA20_EXIT_AFTER_MIN_HOLD` 事件全部为成本后负收益，
合计 `-5151.7275681525 USDT`；216 个 24h vertical exit 合计
`+2938.3764799115 USDT`。这提示退出路径是下一轮的核心研究对象，但它是
看到结果后的诊断，不能直接把“删除 SMA 退出”冒充预注册成功策略。

低于 40% 年化波动的 75 个 OOS 事件合计仅 `+13.863502997 USDT`，同样只
是描述性分组。样本较少且来自已看 archive，不据此新增波动阈值。

## 理由

赚钱目标要求先确认损失来自哪里。gross 已负意味着模型或费用优化无法修复
缺失的交易边际。固定全量分组并保留不利结果，可阻止事后选择最漂亮的市场
状态；仅前向 challenger 则阻止同一历史区间被反复刷成“新 OOS”。

## 拒绝的方案

- 只报告手续费后亏损：拒绝；无法判断策略毛边际。
- 把低波动分组直接升级为策略：拒绝；属于看结果后选阈值。
- 删除全部早退并立即回测宣称改善：拒绝；退出诊断已经被查看。
- 继续训练 XGBoost：拒绝；简单基线仍无经济价值。
- 从 2026-07-01 回填 forward：拒绝；规则在该日期之后才冻结。

## 后果

v1 永久拒绝。已注册 challenger 仍处于未评估状态，不能进入 AI、Paper
放行或真实资金。下一工程步骤是实现事件流级 challenger 与不可回填的
prequential recorder，而不是继续挖掘旧 archive 的最佳分组。
